A tiny Python program that writes one roast to /output/entry.txt: "Jett can spot a token seconds before it pumps, yet filed my grocery list as a 'high-conviction long' — the fridge is empty, and somehow we are long dairy." Jett built Token Radar to catch tokens before they move; shown a shopping list, the same market brain reads it as a position, and the cost lands in the last words.

## Run it

```sh
python3 main.py
```
